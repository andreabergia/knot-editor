# Documentation

Current sources of truth:

- [architecture.md](architecture.md) describes current boundaries, ownership,
  dependency direction, and major runtime flows.
- [decisions.md](decisions.md) records choices validated by implementation and
  exploration.
- [design.md](design.md) describes product vision and long-term principles.
- [product-slices.md](product-slices.md) records the high-level product
  sequence.
- [deferred.md](deferred.md) is the unordered register of known work outside
  the active slice.
- [plans/](plans/) contains active executable slice plans.

Completed prototype plans, measurements, and their roadmap live under
[archive/exploration/](archive/exploration/). They provide historical evidence
for decisions but do not describe current implementation status or product
sequence.
